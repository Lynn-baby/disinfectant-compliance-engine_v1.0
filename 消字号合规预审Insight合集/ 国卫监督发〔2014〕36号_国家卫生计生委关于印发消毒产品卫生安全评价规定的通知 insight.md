# 国家卫生计生委关于印发消毒产品卫生安全评价规定的通知 Insight

## 文档概要

**2014年发布（国卫监督发〔2014〕36号）**，是消毒产品从"行政许可制"向"卫生安全评价+备案制"转型的核心行政规章。定义了产品三分类体系、评价六大内容、检验要求、备案程序、报告有效期及罚则。

## 对合规预审引擎的价值

### 1. 产品三分类体系 — S0 入口路由

第二条将消毒产品分为三类：
- **第一类**（高风险）：医疗器械高水平消毒剂/灭菌剂、皮肤黏膜消毒剂、生物/化学指示物 → 报告有效期4年
- **第二类**（中风险）：其他消毒剂/器械、抗抑菌制剂 → 报告长期有效
- **第三类**（低风险）：抗抑菌制剂外的卫生用品 → 常规管理，无需安全评价

合规引擎的S0入口需要先判定产品类别，再路由到不同的检查流程。

### 2. 评价内容的完整清单 — S0-S7 的顶层框架

第五条定义了卫生安全评价的六大内容，与 WS 628-2018 一致，是合规引擎的最顶层检查维度：
产品标签 + 说明书 + 检验报告 + 企业标准 + 生产许可 + 配方/结构图

### 3. 重新检验的触发条件 — S3 更新逻辑

第十二条列出的三种需重新检验的情形（地址迁移、延长有效期、改变使用范围/方法），可以作为引擎S3的"变更触发规则"：识别到这些情形时，引擎应提示需要新的检验报告。

### 4. 罚则条款 — 合规风险的优先级标注

第十七条列出的违规情形可以作为引擎"风险等级"的判定依据：
- 未做安全评价 → 最高风险（直接违规）
- 评价项目不全 → 高风险
- 有效期过期 → 需更新
- 配方改变未更新报告 → 需补做
