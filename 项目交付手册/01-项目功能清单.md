# 消字号合规预审引擎 — 项目功能清单

> 最后更新：2026-06-10 | 状态：交付就绪 | 测试：20/20 PASS

---

## 一、项目概况

消字号合规预审引擎是一个 Web 应用，品牌方客户上传消毒产品标签（图片/PDF）或直接输入产品信息，系统自动完成合规预审并生成报告。

**技术栈：** Python + FastAPI + SQLite + OCR（Tesseract）

**访问方式：** 浏览器打开服务器地址，Web 界面操作，无需安装客户端。

---

## 二、核心功能

### S0-S7 合规预审流水线

| 阶段 | 功能 | 说明 |
|------|------|------|
| S0 | 输入校验 | 检查产品名称、成分、宣称是否齐全 |
| S1 | 数据就绪 | 结构化产品信息 |
| S2 | 产品分类 | 判定消毒剂/抗菌剂/抑菌剂等类别 |
| S3 | 成分合规 | 成分名称标准化 + 禁用/限用物质匹配 |
| S4 | 风险分级 | R1-R3 三级风险评估（含医疗宣称拦截） |
| S5 | 检测方案 | 根据类别+风险自动生成检测项目清单 |
| S6 | 报价 | 检测项目 → 总价计算 |
| S7 | 报告生成 | Markdown 报告 + JSON 结构化摘要 |

### OCR 文件解析

- 支持格式：PDF / PNG / JPG / BMP / TIFF
- 上传上限：10MB
- 自动提取产品名称、成分列表、功效宣称

## 三、用户系统

### 配额管理

- 每个 IP **3 次免费**预审
- 用完后显示付费提示（¥499/份完整报告）
- **SQLite 持久化存储**，服务器重启不丢失
- localhost 自动无限配额（部署方自用不受限）

### 邮箱验证码登录

- QQ 邮箱 SMTP 发送 6 位验证码
- 验证通过后签发 JWT（72 小时有效）
- DEV 模式：SMTP 未配置时验证码自动显示在页面上

### Admin 管理员面板

- **双重鉴权**：邮箱登录 + Admin Key 同时满足（生产环境）
- localhost 自动拥有管理员权限
- 功能：重置配额、SMTP 邮件测试、复制管理链接

| 措施 | 配置 |
