# 消字号合规预审引擎 — 客户支持速查

> 用途：品牌方客户遇到问题时，按此文档快速定位和解决。
> 适用对象：OPC 顾问（售后支持用）

---

## 一、SMTP 邮件问题

### "验证码收不到"

**排查顺序（按序号执行）：**

1. 检查 `.env` 文件，确认 `SMTP_USER` 和 `SMTP_PASS` 两行都已填写
2. **关键：`SMTP_PASS` 必须是 QQ 邮箱授权码，不是 QQ 登录密码**
3. 如果客户没开授权码：QQ 邮箱网页版 → 设置 → 账户 → POP3/SMTP 服务 → 开启 → 短信验证 → 系统返回 16 位授权码
4. 用测试端点验证：
   ```
   curl -X POST "http://服务器IP:8000/api/admin/smtp-test?key=ADMIN_KEY的值" \
     -H "Content-Type: application/json" \
     -d '{"email":"收件邮箱"}'
   ```
5. 解读返回值：
   - `"success": true` → SMTP 正常，检查客户邮箱垃圾箱
   - `"detail": "SMTP 未配置"` → `.env` 文件未被加载，检查文件位置和格式
   - `"detail": "SMTP 认证失败"` → 授权码错误或已过期，重新获取
   - `"detail": "SMTP 连接失败"` → 网络问题，检查服务器能否访问外网 465 端口

### "客户用的是 163/Gmail/企业邮箱"

修改 `.env` 中以下四行：

```
SMTP_HOST=smtp.163.com        # 163 邮箱
SMTP_PORT=465                 # 或 587（Gmail 用 587）
SMTP_USER=账号@163.com
SMTP_PASS=授权码或应用专用密码
```

> Gmail 需开启"两步验证"后在安全设置中生成"应用专用密码"。

## 二、配额问题

### "还没用几次就提示配额用完"

- 规则：每个公网 IP 有 3 次免费配额
- 多人同网络 → 共享同一个 IP → 共享 3 次配额
- 解决方法：登录 Admin 面板点击"重置配额"，或调用：
  ```
  curl -X POST "http://服务器IP:8000/api/quota/reset?key=ADMIN_KEY"
  ```

### "服务器重启后配额会清零吗？"

**不会。** 配额已存储在 `data/quota.db`（SQLite 数据库），重启不丢失。

### "怎么给某个客户无限配额？"

当前版本不支持按用户分配配额。临时方案：让客户用 localhost 访问（自动无限），或用 Admin Key 定期重置。

## 三、启动和运行问题

### 启动报错：`ModuleNotFoundError: No module named 'server'`

**原因：** 命令执行目录不对。

**正确做法：** 必须在项目根目录（能看到 `server/` 文件夹的地方）执行命令。

```
# 错误 ❌
cd /opt/disinfectant-engine/server
python3 -m uvicorn main:app ...

# 正确 ✅
cd /opt/disinfectant-engine
python3 -m uvicorn server.main:app ...
# 或直接用启动脚本
./run_prod.sh
```

### 端口被占用

换端口启动：

```bash
PORT=8080 ./run_prod.sh
```

### OCR 识别不出文字

需安装 Tesseract OCR 引擎：

```bash
# Ubuntu/Debian
sudo apt install tesseract-ocr

# macOS
brew install tesseract
```

### 上传文件报错 "文件过大"

上限 10MB。让客户压缩图片或使用更低分辨率扫描。
