## 二、最难搞的 6 类客户问题（隐藏在长对话中）

### 难搞类型 1：成分擦边 —「这个成分不在目录里，但我想用」

**场景**：客户产品含二氧化钛（光触媒）、二硫化硒（去屑剂）、铜/锌离子等，不在《消毒产品原料目录清单》(GB 38856，~80种) 中。

**为什么难**：
- 走"新型消毒产品"路径需向国家卫健委申请，耗时数年、成本极高，几乎不可行
- 客户品牌/营销围绕非合规成分建立（如"光触媒消毒液"），改名即失去差异化
- 只能靠"隐藏成分、只写合规成分"的灰色策略

**销售当前应对**：
- 引导客户用合规成分（异丙醇、苯扎氯铵）作为标签上的"主要有效成分"
- 不合规成分不写入包装，仅作 B2B 线下辅助材料展示
- 明确指出这是"埋雷"策略——地方审核不严时能过，但省局抽查或同行举报会翻车

**Agent 需具备的能力**：
- 成分合规速查（输入成分名 → 返回是否在 GB 38856 目录中）
- 替代成分推荐（"二氧化钛不能写，建议用异丙醇做主要有效成分"）
- 风险评级（低/中/高风险，附带翻车概率和后果说明）

---

### 难搞类型 2：跨城市监管套利 —「哪个城市好过备案？」

**场景**：客户在多城市有公司主体，想找审核最松的城市提交备案。

**为什么难**：
- 各地卫生监督所审核标准不一致，且信息不透明
- 错选城市=备案被拒+时间浪费+可能触发同行举报
- 成都在 2019 年儿童消毒品重金属超标事件后极其严格

**销售当前应对**：
- 凭经验给出城市难度排序（成都>上海>深圳>北京>武汉/咸宁>海南）
- 建议避开东莞（分两区、两队人马，处理速度差异大）
- 提醒备案平台全国联网，跨省备案合法但需考虑企业注册地

**Agent 需具备的能力**：
- 城市备案难度数据库（审核严格度、平均周期、是否需要到场）
- 推荐最优备案城市并给出理由

---

### 难搞类型 3：植物提取物合规 —「我是全植物的，能不能做消毒？」

**场景**：客户产品为纯植物提取物配方（除臭、抗菌），想注册为"消毒产品"。

**为什么难**：
- 消毒产品法规要求化学类消毒成分（GB 38856目录内），植物提取物不能做主打消毒成分
- 2021年9月卫健委解读：植物提取物在抗菌产品中可用，但消毒产品不行
- 客户已按"消毒产品"提交了卫生许可证材料，需推倒重来

**销售当前应对**：
- 重分类为"除臭剂"（无需任何字号，不归卫健委管）
- 或走"抗菌/抑菌产品"路径（可用植物成分，标准用 GB 38456 + WS 628）
- 提醒避免黏膜接触声明（否则检测要求大幅增加）

**Agent 需具备的能力**：
- 产品分类决策树（成分+用途 → 推荐注册路径：消毒/抗菌/除臭/化妆品/日化）
- 目前分类路径和后续需要做的检测清单

---

### 难搞类型 4：产品结构不合规 —「能不能在图纸上把这个部件藏起来？」

**场景**：客户产品含禁用组件（等离子+紫外一体机），国家标准明文禁止等离子消毒机配有紫外线发生装置。

**为什么难**：
- 客户不想改硬件，只想在提交的结构图上"不标紫外灯"
- 备案是"形式审查"——只看图纸不看实物，理论上可行但风险极大
- 省局抽查或同行举报可导致产品撤证

**销售当前应对**：
- 建议拆分产品（纯等离子或纯紫外），拒绝为 6000 元代理费承担翻车风险
- 若客户执意隐藏，告知"最坏情况"
- 建议在卫生许可证上预留更多生产品类（为未来产品铺路）

**Agent 需具备的能力**：
- 产品合规检查清单（组件/原理 → 是否触碰国标红线）
- 替代方案生成器（"A+B不合规，建议只做A / 只做B / 改标签为C"）

---

### 难搞类型 5：新冠/病毒功效声明 —「我想在包装上写杀新冠」

**场景**：客户有国外 P3 实验室新冠测试报告，想在中文包装上标注"杀灭新冠病毒"。

**为什么难**：
- 新冠病毒检测必须 P3 实验室（国家级），费用 20 万+/项，全国仅少数几家能做
- 全国仅武汉一家企业成功将"杀新冠"印在包装上，花费 60-80 万
- 2021 年起新规提高生物安全等级要求，P2 实验室报告无效

**销售当前应对**：
- 明确告知不可印在包装上
- 建议私下做检测、保留报告、B2B 线下给客户看
- 备案本身不需要病毒检测——这是纯市场行为

**Agent 需具备的能力**：
- 声明分级指引（包装能写什么/不能写什么、什么可以私下展示）
- 检测费用估算（常规检测 vs 病毒检测 vs 新冠检测，三档价格）

---

### 难搞类型 6：新法规踩线 —「12月1日新国标生效，我的产品还能过吗？」

**场景**：GB 38456 自 2021年12月1日起禁止在抗菌洗浴产品中添加《中国药典》成分。客户产品含二硫化硒（药典成分），且浓度>1%。

**为什么难**：
- 老产品在新规前可能侥幸通过，但新规后二元Pass/Fail
- 各地对新规的理解和执行有时间差（大城市第一时间执行，小城市滞后数月）
- 同行举报风险：别人被拒可凭你的已备案产品申诉，触发追溯性撤证

**销售当前应对**：
- 建议改原料来源描述（二硫化硒 → 温泉提取物衍生物）走植物提取豁免
- 建议等12月1日后向当地卫监确认执行口径再决定
- 提供 CBD（大麻二酚 → 大统素酯多酚）的更名先例作为参考

**Agent 需具备的能力**：
- 法规生效倒计时和过渡期提醒
- 原料名称替代方案库
- 各地执行口径数据库

## 三、标准销售路径

```
开场寒暄 → 需求挖掘 → 技术方案 → 报价 → 异议处理 → 加微结束
   🟢          🟢          🟡        🔴       🔴         🟢
```

| 阶段 | 目的 | 流失风险 | Agent 需支持 |
|------|------|---------|-------------|
| 开场 | 确认身份+产品类型 | 🟢 低 | 自动识别客户提到的产品类别 |
| 需求挖掘 | 了解成分/用途/目标 | 🟢 低 | 问答引导模板（"您的产品主要成分是什么？"） |
| **技术方案** | 给出备案路径 | 🟡 中 | 成分合规速查 + 分类决策树 + 风险评级 |
| **报价** | 费用+周期 | 🔴 高 | 自动报价计算器（检测项+备案服务费） |
| **异议处理** | 解决价格/合规顾虑 | 🔴 高 | 常见异议FAQ + 替代方案推荐 |
| 加微结束 | 发送资料跟进 | 🟢 低 | 自动生成跟进消息 + 资料包 |

## 五、从对话中提取的关键判断规则

### 产品能不能做的决策树

```
客户有产品，想做备案
  ├─ 成分在 GB 38856 目录里？
  │   ├─ 是 → 可以做，走正常流程
  │   └─ 否 → 能用合规成分"代替"吗？
  │       ├─ 能 → 走隐藏策略（标注风险）
  │       └─ 不能 → 重分类（抗菌/除臭/化妆品） 或 放弃
  ├─ 产品结构合规吗？
  │   ├─ 合 → 继续
  │   └─ 不合 → 能改结构/图纸吗？
  │       ├─ 能 → 修改后继续
  │       └─ 不能 → 明确告知风险，拒绝代理
  ├─ 有卫生许可证吗？
  │   ├─ 有 → 查看生产范围是否匹配
  │   └─ 没有 → 先办许可证，再备案
  └─ 想在哪里备案？
      ├─ 公司注册地 → 正常流程
      └─ 外省 → 可行但需确认

能接 → 报价（检测费+服务费+周期）
不能接 → 给出替代方案或明确拒绝
```

### 六大红色信号（立即预警）

1. **客户说"我这个成分比较特殊"** → 大概率不在目录里
2. **客户说"我们之前问过别的机构说做不了"** → 产品有硬伤
3. **客户说"先备案着，我这边已经在卖了"** → 在售未备案，需追溯合规
4. **客户问"哪个城市比较容易过"** → 明知产品有问题，在找监管套利
5. **客户说"能不能不在标签上写这个成分"** → 成分不合规
6. **客户说"国外都能卖，国内为什么不行"** → 需解释中外法规差异

## 六、Agent 对话策略建议

### 话术模式

```
销售: [开场识别] "您好，您是做[产品类型]的，想了解[备案/检测/法规]是吧？"
           ↓
销售: [需求挖掘] "您产品的有效成分是什么？主要用在哪里？"
           ↓
销售: [合规判断] "这个成分/结构，根据[GB XXXX]，可以/不可以..."
           ↓
销售: [方案输出] "建议您走[路径A]，需要做[X项检测]，费用约[Y元]，周期[Z个月]"
           ↓
销售: [异议处理] "费用虽然不低，但包含[A+B+C]，确保合规..."
           ↓
销售: [收尾] "加个微信，我把详细报价和法规依据发您"
```

### 关键原则

- **不硬推**：客户产品不合规时，不要为代理费硬接（拒单比翻车好）
- **给退路**：每个"不能做"后面必须跟一个"但你可以..."
- **说风险**：隐藏成分策略必须明确告知翻车概率和后果
- **留记录**：所有灰色建议需在沟通中留下"已告知风险"的记录
