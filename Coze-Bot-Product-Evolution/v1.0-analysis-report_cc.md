## 二、问题诊断

### 2.1 Prompt 问题

| 严重程度 | 问题 | 说明 |
|---------|------|------|
| **高** | 太短 | 101 字无法定义清晰的角色、步骤流程、输出格式 |
| **高** | 无步骤流程 | 没有告诉 Bot "先了解产品 → 再查询知识库 → 最后给建议" 的执行顺序 |
| **中** | 无示例（Few-shot） | 缺少对话示例，模型行为不稳定，容易偏离预期 |
| **中** | 无兜底策略 | 知识库查不到相关信息时如何回复？没有定义降级方案 |
| **低** | 无输出格式规范 | 每次回复结构可能不同，用户体验不一致 |

### 2.2 知识库问题

| 严重程度 | 问题 | 说明 |
|---------|------|------|
| **高** | 从未测试 | `hit_count: 0`，不知道检索召回率和准确率 |
| **中** | 数据量偏小 | 4 篇共 ~6,500 字，覆盖的合规场景有限 |
| **中** | 命名不匹配 | 库名叫 `ai_sale_agent_kb_upload`，与"消毒合规"业务语义无关 |
| **低** | 分块偏大 | `max_tokens: 1000`，可能影响检索精度 |

### 2.3 配置问题

| 严重程度 | 问题 | 说明 |
|---------|------|------|
| **高** | 上下文仅 3 轮 | 备案咨询通常需多轮追问（产品类型 → 成分分析 → 检测项目 → 材料清单），3 轮后就遗忘上下文 |
| **中** | 无工作流 | 备案可行性判断、检测项目推荐等是标准化流程，适合用工作流固定逻辑 |
| **中** | 无变量 | 无法记住用户的产品类型、当前咨询阶段 |
| **低** | 纯文本输入 | 用户无法上传产品标签、检测报告图片进行审核 |

## 三、改进建议（按优先级）

### P0 — 必须修复

**1. 重写 Prompt**

当前 101 字 → 建议扩充至 800-1500 字，结构化组织：

```
[角色与定位]
- 你是谁、服务谁、专业领域

[工作流程]
- 第1步：了解产品信息（类型、成分、用途）
- 第2步：检索知识库匹配答案
- 第3步：给出专业建议
- 第4步：提供下一步行动指引

[知识库使用规则]
- 何时检索、如何引用来源

[输出格式要求]
- 回复结构模板

[边界约束]
- 不报价、不承诺、不评价竞品

[兜底策略]
- 知识库无匹配时如何回应

[对话示例]
- 2-3 组标准问答
```

**2. 上下文轮数 3 → 10+**

消毒合规咨询流程长，建议至少 10 轮。

**3. 知识库检索测试**

用 Suggested Questions 和变体问题做一轮 RAG 评测，验证：
- 召回率（该命中的是否命中）
- 准确率（命中内容是否相关）
- 回答质量（基于检索结果的回答是否专业）

### P1 — 强烈建议

**4. 增加工作流**

| 工作流 | 作用 |
|--------|------|
| 备案可行性判断 | 根据产品类型/成分，走决策树判断能否备案 |
| 检测项目匹配 | 根据产品类型，自动列出需要的检测项目清单 |
| 材料清单生成 | 根据备案类型，生成所需材料列表 |

**5. 增加变量**

| 变量 | 用途 |
|------|------|
| `product_type` | 记住用户产品类型（消毒液/消毒器械/卫生用品/抗抑菌制剂） |
| `consult_phase` | 记住咨询阶段（初次了解/准备材料中/已提交备案） |
| `product_name` | 记住用户的产品名称 |

**6. 优化知识库**

- 每篇文档扩充至 3,000-5,000 字
- 按产品类型拆分为独立知识库（消毒液知识库、消毒器械知识库等）
- 增加 FAQ 高频问题文档
- 增加法规原文/标准条款文档

### P2 — 锦上添花

**7. 支持图片上传**：用户上传产品标签、检测报告，Bot 能初步审核
**8. 优化建议回复**：根据上下文引导用户给出产品类型等关键信息
**9. 收集用户反馈**：对话结束后收集满意度评分

## 四、v2.0 建议方向

### 核心目标

> **把"空壳 Bot"变成"能实际服务客户的 Bot"**

v1.0 已经搭好了框架（Bot 创建、知识库上传、插件配置），但：
- Prompt 太简单，Bot 行为不可控
- 知识库太小且从未测试
- 没有用户使用过，缺乏真实反馈

v2.0 的核心任务不是加新功能，而是**夯实基础**：

### 建议路线

```
第一步（1-2 天）：Prompt 重写 + 上下文延长
  ↓  改动小、收益大，立刻提升回答质量
第二步（2-3 天）：知识库扩充 + RAG 测试
  ↓  让 Bot 真正有专业知识可查
第三步（3-5 天）：工作流 + 变量
  ↓  让体验从"能用"到"好用"
第四步（持续）：投放使用 + 收集反馈 + 迭代
```
