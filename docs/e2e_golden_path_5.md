# E2E Golden Path 测试 — 5 条完整对话链路

## 使用方法

在 Coze Workflow 中逐条模拟以下对话，每轮输入用户说的话，检查引擎回复是否符合预期。
每条链路走完 S0→S7，验证全流程不中断、输出结构完整。

---

## 用例 1：国产抗抑菌剂 — R1 低风险标准路径

**场景**：品牌方咨询免洗洗手液，成分清晰，国产，正常备案路径。

```
轮1
  用户: 你好，帮我看看一款免洗洗手液能不能做消字号备案
  引擎: [S0→S1] 问候 + 引导提供产品信息
  验证: 回复不含合规结论，在追问缺失信息

轮2
  用户: 含75%酒精和甘油，国产的，我是品牌方
  引擎: [S1] 确认已有信息（产品名/剂型/成分/产地/角色），追问宣称功效
  验证: 已采集字段被正确识别和确认

轮3
  用户: 主打抑菌
  引擎: [S1→S2→S3→S4→S5→S6→S7] 6字段齐全，自动推进全链路
  验证:
    ✅ S2 品类判定 = 抗抑菌剂
    ✅ S3 成分合规 = 酒精✅ 甘油✅（引用《消毒剂原料清单》）
    ✅ S4 风险等级 = R1 低风险
    ✅ S5 检测方案 含7项（有效成分/pH/抑菌/稳定性/毒理/重金属/微生物）
    ✅ S6 报价 含税费明细
    ✅ S7 预审摘要 含5章节 + 声明
  最终输出: 完整的意向预审报告
```

## 用例 2：进口消毒剂 — R2 中风险 + 免责声明

**场景**：进口消毒喷雾，成分正常，但因进口自动提一级到 R2。

```
轮1
  用户: 进口的消毒喷雾，次氯酸钠，日本产的，品牌方
  引擎: [S1] 已采集 品名/剂型/成分/产地/角色，追问功效

轮2
  用户: 就是消毒用的
  引擎: [全链路]
  验证:
    ✅ S2 品类判定 = 普通消毒剂
    ✅ S3 成分 = 次氯酸钠✅
    ✅ S4 风险等级 = R2 中风险
       触发条件包含"进口产品"
       输出含免责声明
    ✅ S5 检测方案 含进口备注
    ✅ S6 报价正常
    ✅ S7 摘要含 R2 注意事项
```

## 用例 3：含禁用成分 — R3 高风险，自动阻断报价

**场景**：产品含三氯生（禁用），触发 R3，不生成检测方案和报价。

```
轮1
  用户: 消毒液，成分是三氯生和纯化水，国产，品牌方，消毒用
  引擎: [S1] 6字段一次齐 → 全链路
  验证:
    ✅ S2 品类判定 = 普通消毒剂
    ✅ S3 成分合规 = 三氯生❌（引用法规）
    ✅ S4 风险等级 = R3 高风险
       触发条件含"含禁用成分"
       明确说明"禁止报价"
    ❌ S5 不生成检测方案
    ❌ S6 不生成报价
    ✅ S7 输出高风险摘要 + 建议转人工
```

## 用例 4：信息残缺 → 多轮追问 → 完整路径

**场景**：客户一开始只说了产品名，引擎逐轮追问直到信息齐全。

```
轮1
  用户: 帮我看看这个产品
  引擎: [S1] 追问产品名+剂型（最多2个字段）
  验证: 不会一次性抛出6个问题

轮2
  用户: 洗手液
  引擎: [S1] 确认产品名+剂型，追问成分+功效

轮3
  用户: 75%酒精，抑菌
  引擎: [S1] 确认成分+功效，追问产地+角色（最后2个必采字段）

轮4
  用户: 国产，品牌方
  引擎: [全链路] 6字段齐全 → 自动推进
  验证:
    ✅ 品类=抗抑菌剂, 风险=R1
    ✅ 完整预审报告
```

## 用例 5：中途修改变量 → 触发回退 → 自动重跑

**场景**：客户在信息采集完成后修改了关键字段，引擎回退并重算。

```
轮1
  用户: 免洗洗手液，75%酒精，抑菌，国产，品牌方
  引擎: [全链路] R1 低风险，7项检测，报价XX

轮2
  用户: 等下，忘了说这是进口的
  引擎: [中断] 检测到产地变更（国产→进口）
        "我注意到产地发生了变化，这个修改会影响全部分析链路。
         确认修改后我会自动重新分析。还有其他需要调整的吗？"

轮3
  用户: 没有了
  引擎: [回退到S2→重跑S3/S4/S5/S6/S7]
  验证:
    ✅ S2 重新判定品类（进口路径）
    ✅ S3 成分重新检查
    ✅ S4 风险从 R1 → R2（进口触发）
    ✅ S5 检测方案含进口备注
    ✅ S6 报价重新计算
    ✅ S7 摘要含 R2 免责声明
```
